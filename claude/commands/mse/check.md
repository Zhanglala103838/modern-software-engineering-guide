---
description: 工程规范体检 — 给当前项目定段位 + 给出风险下降/投入最高的几条行动
argument-hint: "[可选:项目路径,默认当前目录]"
---

先调用 skill `engineering-standards`(加载工程规范基线 + 段位路由)。

然后对目标项目(`$ARGUMENTS` 为空则当前目录)做**只读体检**:

1. 采集信号:`git status -s | wc -l`(未提交数)、有无 CI(.github/.gitea workflows)、有无真实测试、最大源文件行数、`.bak`/构建产物入库情况、依赖是否锁精确版本。
2. 按 SKILL 的段位表定位:🧱棕地地板 / 🏗️过渡 / ✅绿地 / 🛡️治理天花板,并说明依据。
3. 给出**该段位对应 SPEC 的哪几部分** + **按"风险下降/投入"排序的 top 3 行动**(每条注明对应 SPEC 条目)。
4. 全程只读,不改文件。最后一句给"下一步建议"(可接 `/mse:fix` 做第一条)。
